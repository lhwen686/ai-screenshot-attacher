# Project Instructions
- Use codex-mem as persistent project memory.
- At session start, search memories for this project.
- Before broad architecture/layout/dependency/deployment changes, search relevant memories.
- After meaningful work, save a concise memory entry.
- Never save secrets, API keys, tokens, cookies, passwords, or private credentials.
- Never launch, close, restart, or modify Chrome/browser extension state with command-line flags or scripts. In particular, do not use flags such as `--disable-extensions-except`, `--load-extension`, temporary profile manipulation, or automation that can disable existing extensions. This is required because Cold Turkey Blocker may force-close/block Chrome if its extension is disabled. For browser extension installation or loading, provide manual UI steps only unless the user explicitly approves a safe action.
