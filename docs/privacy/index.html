Privacy policy

Conservative by design

AI Screenshot Attacher has one purpose: attach a clipboard screenshot to a supported AI chat page after your action, or while you have explicitly enabled automatic mode.

AI Screenshot Attacher 只有一个用途：在你触发后，或在你明确开启自动模式后，把剪贴板截图附加到受支持的 AI 对话页面。

English

Data handling

  • Clipboard images are read in the extension's MV3 offscreen document, then passed to the selected supported AI page for attachment.
  • The selected AI website receives the image because the user chose to attach it there.
  • The extension does not upload screenshots to an extension-author server.
  • The extension does not store screenshot history.
  • The extension does not read or store chat history.
  • The extension does not collect analytics, telemetry, account identifiers, or browsing history.
  • The extension does not automatically send AI messages.
  • Settings are stored in chrome.storage.sync and may sync with the browser account.
  • The latest operation status and automatic-mode duplicate state are stored only in chrome.storage.local.

简体中文

数据处理

  • 剪贴板图片在插件的 MV3 offscreen document 中读取，然后传给用户选择的受支持 AI 页面用于附加。
  • 用户选择附加图片到目标 AI 网站时，目标 AI 网站会收到该图片。
  • 插件不会把截图上传到插件作者服务器。
  • 插件不保存截图历史。
  • 插件不读取或保存聊天记录。
  • 插件不收集 analytics、遥测、账号标识或浏览历史。
  • 插件不会自动发送 AI 消息。
  • 设置保存在 chrome.storage.sync 中，可能随浏览器账号同步。
  • 最近一次操作状态和自动模式去重状态仅保存在 chrome.storage.local 中。

English

Permissions

  • clipboardRead: reads a clipboard image after a manual trigger or enabled automatic mode.
  • clipboardWrite: for a manual Gemini or Doubao action, may prepare the already captured image immediately before a browser paste; it also restores the image after a failed attachment when fallback is enabled. Automatic mode does not use the real-paste path.
  • tabs: finds, opens, focuses, and monitors supported AI pages; also opens user-requested help links.
  • activeTab: supports temporary user-invoked page feedback on the current tab.
  • scripting: injects the attachment runtime into supported AI pages and shows page feedback.
  • storage: saves settings, latest operation status, and duplicate-suppression state.
  • offscreen: enables MV3 clipboard access from an offscreen document.

简体中文

权限说明

  • clipboardRead：在手动触发或已开启自动模式时读取剪贴板图片。
  • clipboardWrite：手动附加到 Gemini 或豆包时，可能会在浏览器粘贴前准备已捕获图片； 附加失败且回退开启时也会写回截图。自动模式不使用真实粘贴路径。
  • tabs：查找、打开、聚焦和监控受支持 AI 页面，也用于打开用户请求的帮助链接。
  • activeTab：支持用户触发后的当前标签页临时反馈。
  • scripting：向受支持 AI 页面注入附加运行时代码，并显示页面反馈。
  • storage：保存设置、最近一次操作状态和去重状态。
  • offscreen：通过 MV3 offscreen document 访问剪贴板。

English

Host permissions

Host permissions are limited to ChatGPT, Claude, Gemini, and Doubao pages. The extension does not request access to every website.

简体中文

站点权限

站点权限仅限 ChatGPT、Claude、Gemini 和豆包页面。插件不请求访问所有网站。
