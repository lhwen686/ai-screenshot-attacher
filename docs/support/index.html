English

Before reporting

  • Copy a fresh screenshot to the clipboard.
  • Confirm you are logged in to the target AI site.
  • Open the extension popup and note the latest result message.
  • Check whether manual paste still works after the fallback focuses the input.

简体中文

反馈前请检查

  • 重新复制一张新截图到剪贴板。
  • 确认已经登录目标 AI 网站。
  • 打开插件弹窗，记录最近一次结果信息。
  • 确认回退聚焦输入框后，手动粘贴是否仍可用。

What to include

  • Extension version.
  • Whether you used a shortcut, popup button, or automatic mode.
  • The visible error or latest popup result.
