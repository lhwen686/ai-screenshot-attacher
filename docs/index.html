What it does

  • Reads a clipboard image after a shortcut or popup action.
  • Opens or focuses the selected supported AI page.
  • Attaches the image to the page input when the target site allows it.
  • Falls back to manual paste guidance when automatic attachment is rejected.

它做什么

  • 在快捷键或弹窗按钮触发后读取剪贴板图片。
  • 打开或聚焦你选择的受支持 AI 页面。
  • 在目标网站允许时，把图片附加到输入区。
  • 如果自动附加被网站拒绝，会提示你手动粘贴。

Privacy boundary

No analytics are included. The extension does not read chat history, does not store screenshot history, and does not send AI messages automatically.

隐私边界

没有 analytics。插件不读取聊天记录，不保存截图历史，也不会自动发送 AI 消息。
